# Glossário

Definições curtas de conceitos importantes, conectadas a conteúdos maiores em outras categorias.

Cada entrada de glossário segue o mesmo frontmatter de [`schemas/content.schema.json`](../../schemas/content.schema.json), com `type: "concept"` e `category: "glossary"`, mas o corpo pode ser mais curto do que um concept completo — o objetivo é definir rapidamente, não explicar em profundidade (para isso, aponte via `related` para o conceito completo em outra categoria, quando existir).
